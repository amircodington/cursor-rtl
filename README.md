# Cursor RTL — رفع سراسری فارسی / عربی / عبری

اکستنشن Cursor که مشکل **راست‌چین نشدن چت و به‌هم‌ریختن فارسی+انگلیسی وسط جمله** را در کل Cursor درست می‌کند: Chat، Agent، Plan، ورودی پرامپت، و در صورت نیاز ویرایشگر.

این یک فورک از [motcke/cursor-ext-rtl](https://github.com/motcke/cursor-ext-rtl) (Apache-2.0) است؛ تله‌متری حذف شده و CSS برای جملات مختلط فارسی+انگلیسی تقویت شده.

## نصب (یک‌بار روی Cursor دسکتاپ شما)

1. فایل `cursor-rtl-2.1.1.vsix` را از [Releases](https://github.com/amircodington/cursor-rtl/releases) بگیرید (یا با `npm run package` بسازید).
2. در Cursor: `Cmd/Ctrl+Shift+P` → **Extensions: Install from VSIX…** → همان فایل را انتخاب کنید.
3. دوباره Command Palette: **`Cursor RTL: فعال‌سازی / رفع بعد از آپدیت`**
4. اگر اجازهٔ نوشتن روی فایل‌های Cursor خواست، تأیید کنید (روی macOS/Windows گاهی نیاز به دسترسی ادمین است).
5. پنجره را Reload کنید.

بعد از این، وضعیت در نوار پایین باید **`RTL: ON`** باشد و در همه پنجره‌ها اعمال شود.

## ساخت VSIX از سورس

```bash
npm install
npm run package
```

فایل `cursor-rtl-*.vsix` ساخته می‌شود.

## دستورات

| دستور | کار |
| --- | --- |
| `Cursor RTL: فعال‌سازی / رفع بعد از آپدیت` | پچ سراسری روی Cursor |
| `Cursor RTL: غیرفعال‌سازی` | برگرداندن فایل‌های اصلی |
| `Cursor RTL: وضعیت` | بررسی روشن/خاموش بودن پچ |
| `Cursor RTL: جهت ویرایشگر کد` | Auto / Always / Off برای Monaco |
| `Cursor RTL: تشخیص مشکل` | گزارش تشخیصی |

## چه چیزی درست می‌شود؟

- پاراگراف‌های فارسی راست‌چین می‌شوند (`dir="rtl"` + `unicode-bidi: isolate`).
- کلمات انگلیسی وسط جمله (مثل `API`، `Online`، نام فایل) ترتیب فارسی را به‌هم نمی‌زنند.
- بلوک‌های کد LTR می‌مانند.
- بعد از آپدیت Cursor، اکستنشن معمولاً خودش پچ را دوباره اعمال می‌کند؛ اگر نه، همان دستور فعال‌سازی را بزنید.

## نکته مهم

Cursor به‌صورت داخلی هنوز RTL کامل ندارد؛ این اکستنشن با پچ `preload.js` اسکریپت جهت‌بندی را به **همه پنجره‌ها** تزریق می‌کند. بدون مرحلهٔ **فعال‌سازی** فقط نصب اکستنشن کافی نیست.
